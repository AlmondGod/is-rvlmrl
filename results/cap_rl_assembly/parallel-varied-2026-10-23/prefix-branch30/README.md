# Experimental worker-local prefix branching

One full native/Python snapshot is retained per runner. Its seed, physical
provenance and parsed completed-call prefix must match the next program. It
retains source fingerprints and explicit origin-episode receipts. It never
exposes snapshot state to the policy or predicts a reward. The active learner
does not use this experimental runner. Production needs additional origin-file
binding, Linux validation, bounded queue integration and memory measurements.

The short check branches after the first position-member call: the sibling
continues assembly, while the tested program calls `stop()`. Both the fresh
and reused stop programs match all 574×155 states and every non-timing outcome.
The fresh program takes 67.62 seconds, its reused execution 8.03 seconds, with a
separately paid 80.72-second origin run. This early stop is not assembly success
or whole-RL throughput. A complete 22-call branch comparison, changing only
the last two panel-nailing indices, is running with a nine-call snapshot.
